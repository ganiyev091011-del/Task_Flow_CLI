# Task_Flow_CLI
This program is created to be able to use multiple functions in To-Do Lists. By the hold of this program, the user not only can add, remove or mark the task as done, but also, he can sort the tasks by their priority (1- highest, 5-lowest), he can actually know how much development he did by finishing task in percentages and search for that exact task by its title, this method will help the user to find the task that he needed easier. Not only that, by the help of using titles, the user can group several similar tasks in one name. This program is created to make students, self-learners and other users digital lifes more prodative.
